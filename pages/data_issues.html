Data Issues, Problems and Errors


  • Buoy Data
    • ERDDAP stopped reporting on 04-21-2025
    • Filtered out placeholder or faulty buoy positions recorded as (-90, -180), which are not valid for Arctic sea ice locations.
    • The UW IABP data had years < 2010 and > 2025, which disagrees with the table data on https://iabp.apl.uw.edu/TABLES/ArcticTable.html
    • Arctic buoy page on UW IABP has buoys with latitude < 0. These buoys, like 300534062075100, could have been moved to Antarctic region.
    • Omitted buoys that do not include midnight readings, as those are required to anchor daily drift calculations. (e.g. 300434065758620)
    • There are a few occurances of only one observation, so drift cannot be computed. (e.g. 300434065169030)
    • Handled corrupted or blank Day-of-Year (DOY) values by coercing non-numeric entries to NaN and dropping those rows.
  • SAR and Buoy Location Analysis
    • Some obsevations just had one SAR drift row. Since calculations need more than one row to measure difference in lon/lat, the observations were duplicated with the next lon/lat set to the previous ending lon/lat
    • Mutiple rows with same `lon1` and `lat1` positions but different `Lon2` and `Lat2` positions. The last row of these observations set `lon1`=`lon2` and `lat1`=`lat2`.
    • First and last rows with equal `lon1` and `Lon1`. The observations in between the first and last differ. The code updated the last `lon1` = `lon2` and last `lat1`=`lat2`.
    • Removed observations where `orig_bearing` = 0. The values for these observations are incorrect
